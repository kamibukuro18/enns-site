# Freestyle Dining E-nNS 公式サイト一式

## ファイル
| ファイル | 中身 |
|---|---|
| `public/index.html` | 公式サイト本体（1ファイル完結・スマホ対応） |
| `public/admin.html` | お店用の予約管理画面（スマホで使える） |
| `gas/Code.gs` | 予約の受付API（Google Apps Script＋スプレッドシート） |

## サイトの構成
ヒーロー（写真スライド・本日の営業状況）→ お知らせ → こだわり → 名物4品 → 宴会コース（8品・飲み放題・注意事項）→ グランドメニュー（らーめん／料理／パスタ・ピザ／おつまみ／ドリンク、食べログ掲載の全品と価格）→ 利用シーン → ギャラリー（拡大表示つき）→ ネット予約 → よくある質問 → 店舗情報・地図・ルート案内 → Instagram誘導 → フッター
スマホでは下部に「電話／アクセス／ネット予約」の固定バーが出ます。Googleの検索結果に店舗情報が出やすくなる構造化データ（営業時間・住所・電話）も入っています。

## 予約システムでできること
- お客様：人数 → 日付 → 時間（空き状況つき）→ プラン（コースの金額は自動計算・生ビール飲み放題オプションあり）→ 目的 → 連絡先 → 確認 → 予約番号発行
- 席の判定：同時に店内にいる人数が40席を超えないように自動で調整（1組2.5時間の想定）
- 20名以上と、しゃぶしゃぶ・特製鍋は「相談中」として受け付け、お店から折り返し連絡
- お店とお客様の両方に確認メールが届き、来店前日の17時台にリマインドメールが自動で届く
- 管理画面：今日／明日／今週の予約一覧、組数・人数・混み具合、ステータス変更（予約／相談中／確定／キャンセル／来店済／無断キャンセル）、店メモ、時間帯ごとの受付停止、臨時休業の設定

## 本番化の手順（約15分）
1. お店のGoogleアカウントで新しいスプレッドシートを作る
2. 「拡張機能 → Apps Script」を開き、`gas/Code.gs` の中身を貼り付ける
3. 先頭の `SHOP_EMAIL` を、予約通知を受け取るメールアドレスに書き換える
4. 関数 `setup` を選んで実行し、権限を承認する
   - 「予約」「受付停止」シートとリマインドの自動実行が作られます
   - 実行ログに **管理パスワード** が表示されるので控えておく
5. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」で、実行ユーザー「自分」、アクセスできるユーザー「全員」にしてデプロイ
6. 発行されたURLを、`index.html` の `CONFIG.API_URL` と `admin.html` の `API_URL` の両方に貼る
7. `index.html` と `admin.html` を公開サーバー（Netlify／Cloudflare Pages／GitHub Pages など。どれも無料）に置く
8. 管理画面のURL（…/admin.html）は、お店のスマホのホーム画面に追加しておくと便利です

`API_URL` が空のあいだはデモモードで、予約は見ているブラウザの中にだけ保存されます（同じブラウザで admin.html を開くと、デモの予約が管理画面に出ます）。

## 写真について（公開前に必ず確認）
- 今の写真は、商用利用OKのフリー素材（Unsplash）から料理・店内のイメージに近いものを選んでいます。実際のお店の料理・店内の写真ではないので、フッターに「掲載写真はイメージです」と表示しています
- 食べログやInstagramの写真は、撮った人（お店や投稿者）の許可なしには使えません。お店の写真をもらえたら差し替えるのがベストです
- 差し替え方：`images/` フォルダに写真を置き、`index.html` の `IMG` の値を `"images/ramen.jpg"` のように書き換えて、`PHOTO_IS_SAMPLE` を `false` にする
- 必要な写真（優先順）：塩らーめん、濃厚まぜそば、サガリステーキ、ハンバーグ、店内（カウンター・テーブル）、外観、宴会の様子、唐揚げ・ピザ・パスタ・鍋

## お店に確認したいこと
- ドリンクメニューの価格（食べログに載っていないので、今は品目だけ）
- 「時価」になっている料理（しゃぶしゃぶ、カレー、焼きそば、鶏皮餃子、プッタネスカ、ボンゴレ春雨など）の価格
- メニューの価格は食べログの2023年時点の情報です。最新の価格
- 予約の受付時間（今は平日18:00〜21:30、土曜18:00〜20:00の入店）と、1組の滞在時間の想定
- 祝前日の営業時間（食べログの表記が分かりにくいため、今は通常どおりにしています）
- 臨時休業や祝日は管理画面から設定できます。年末年始（12/30〜1/3）は仮で休みにしています

## 調整できる設定（index.html の CONFIG と Code.gs の CFG。両方そろえる）
席数 `capacity`／滞在時間 `stayHours`／何日先まで `maxDaysAhead`／当日の締切 `sameDayCutoffMin`／貸切相談にする人数 `largeGroup`／曜日ごとの受付時間 `slotsByDow`／祝日 `holidays`
